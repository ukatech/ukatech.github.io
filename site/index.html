MCP サーバーから引くには

YAYA・里々・華和梨のドキュメントと、UKADOC 仕様書・SSP ヘルプの 5 つは、伺かの技術ドキュメントを検索できる MCP サーバー ukagaka-doc-mcp からも引けます。AI エージェントに組み込むと、キーワード検索と本文の取得ができます。

  • 手軽に使うなら、公開されているサーバー https://ssp.shillest.net/ukadoc/mcp を、MCP クライアントにリモートサーバー (Streamable HTTP) として登録する
  • 手元で動かすなら、Node.js 22 以上で npx ukagaka-doc-mcp を実行する (インストール不要)。MCP クライアントには、コマンド npx・引数 ukagaka-doc-mcp のサーバーとして登録する
  • どちらでも、次の 3 つのツールが使える list_categories search_docs get_doc

ドキュメントはスナップショットを検索する仕組みで、週に 1 回更新されるため、このサイトの最新の内容とは差が出ることがあります。npx で動かす場合はスナップショットを同梱していて、実行中に外部のネットワークへはアクセスしません。ほかに蒼空 Wiki・湊 docs・Pasta docs も引けます。MCP を使わない場合は llms.txt から各ドキュメントの入口をたどれます。

一覧に載せるには

どちらのサービスも、GitHub のリポジトリに特定のトピックを付けると、自動で巡回して一覧に載せます。トピックはリポジトリのトップページ、About 欄の歯車から追加できます。

偽SoSiReMi

  • #sosiremi を付ける
  • 種別を表すトピックを、次のいずれか付ける #ukagaka-ghost #ukagaka-shell #ukagaka-balloon #ukagaka-plugin #ukagaka-supplement
  • 最新のリリースに NAR ファイルを添付する
  • リポジトリのルートに readme.txt を置く

一覧には最新リリースの NAR が載り、インストール用のリンクも付きます。作者の ID で絞り込む場合は https://nikolat.github.io/sosiremi/author/{作者のID}/ の形式です。

偽SiReFaSo

  • #sirefaso を付ける
  • ukagaka- で始まる種別のトピックを付ける。実際に使われているものの例 #ukagaka-ghost #ukagaka-shell #ukagaka-balloon #ukagaka-plugin #ukagaka-saori #ukagaka-shiori #ukagaka-baseware #ukagaka-tool #ukagaka-webapp #ukagaka-spec #ukagaka-supplement

リリースの有無は問いません。フォークも対象で、リポジトリの最終更新日時が一覧に反映されます。トピックの後ろの語がそのまま種別になり、種別ごとの一覧ページ (https://nikolat.github.io/sirefaso/saori/ など) ができます。
