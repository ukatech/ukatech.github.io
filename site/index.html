伺かのベースウェア周辺で使われる SHIORI やツール類を開発・保守しているチームです。

SHIORI

  • YAYA

    Yet Another AYA

    C言語に近い構文で書ける、汎用性の高い SHIORI です。豊富な組み込み関数を備え、SAORI としても動作します。テンプレートゴースト「紺野ややめ」から始められます。

    ドキュメント 最新リリース テンプレート: 紺野ややめ

  • 里々

    Yet Another SATORI

    台本を書くような感覚でトークを記述できる SHIORI です。シンプルな記法で、プログラミングに不慣れでもゴーストを作り始めやすくなっています。

    ドキュメント 最新リリース テンプレート: ポストと狛犬 里々wiki(プロジェクト外: ユーザー視点の解説)

  • 華和梨

    プログラマブル準AI

    単語の組み合わせとインラインスクリプト (KIS) で会話を組み立てる SHIORI です。SHIORI/2.x と SHIORI/3.0 に対応しています。

    ドキュメント 最新リリース

ライブラリ・ツール

  • CSAORI

    SAORI・プラグインを C++ で作るための基本ライブラリです。

    GitHub リポジトリ

  • ssp-i18n

    SSP の多言語リソースです。英語・中国語 (簡体/繁体)・韓国語の言語パックを管理しています。

    GitHub リポジトリ 最新リリース

  • jsstp-lib

    Web ページや Node.js から SSTP でゴーストと通信するための JavaScript ライブラリです。npm でも配布しています。

    ドキュメント GitHub リポジトリ

  • metainfo-standard

    ゴーストの情報 (プレビュー画像やリンクなど) を記述するための共通規格です。

    仕様 GitHub リポジトリ

  • GhostDist

    ゴーストのネットワーク更新ファイル生成・NAR 作成・FTP アップロードを自動化する Windows ツールです。

    GitHub リポジトリ 最新リリース

  • SSPBundleTool

    自己解凍形式の SSP に initial_install.nar を同梱し、ゴースト同梱版の SSP を作る Windows ツールです。

    GitHub リポジトリ 最新リリース

  • 偽SiReFaSo
